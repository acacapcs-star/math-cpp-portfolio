## 專題列表與說明
### 1. Bingo（小竹 Bingo）

在此題中，我一開始的直覺作法是，
每次叫到一個數字時，就重新走訪整個二維陣列，
逐一檢查所有座標，確認該數值所在的位置。

由於盤面本身是以二維陣列儲存，
空間複雜度為 O(N²)，
而若每次叫號都重新掃描整張盤面，
時間複雜度同樣會達到 O(N²)。

考量到此題會有多次叫號（最多可達數百次），
這樣的作法會造成大量重複的檢測。
因此我在讀入資料時，
額外建立一個「數值 → 座標 (x, y)」的對照結構，
先把每個數字在盤面中的位置記錄下來。

這樣在之後每次叫號時，
只需要直接查詢該數字對應的座標，
即可立刻更新該行、該列（以及斜線）的狀態，
避免反覆掃描整個盤面。

#### 複雜度分析
- **時間複雜度**：理論上仍為 O(N²)，但透過預處理大幅降低重複掃描的次數
- **空間複雜度**：使用 N × N 的二維陣列與額外的座標對照結構，整體為 O(N²)
